## 이진 트리
트리는 나무 Tree이고, 뿌리형태이다. 가지치가 하면서 분류한다.<br>
각 위치를 노드라고 한다. 각 노드는 선(edge, 에지)로 연결되어있다.<br>
위 노드와 아래노드를 부모와 자식관계라고 한다.<br>
자식노드의 개수를 차수(degree)라고 한다<br>
자식이 없는, 차수가 없는 노드를 리프라고 한다.<br>
트리의 차수는 가장 높은 차수의 노드를 기준으로 한다.<br>

**이진트리란?**<br>
이진트리:이진트리는 모든 노드의 자식이 최대 2개인 트리다.<br>
전형적인 이진트리: <br>
맨위에있는 노드를 루트라고 부른다.<br>
맨 위 중심 왼쪽으로 가지치기한 트리를 왼쪽 서브트리라고 부른다.<br>
맨 위 중심 오른쪽으로 가지치기한 트리를 오른쪽 서브트리라고 부른다.<br>
오른쪽 서브트리 안에서는 왼쪽 서브트리가 없다.<br>
왼쪽 서브트리 안에서는 오른쪽 서브트리가 없다.<br>
이진트리에는 번호를 부여할 수있다. 위에서 아래로, 왼쪽부터 오른쪽으로 붙인다.<br>

**이진트리의 종류**<br>
1.포화이진트리<br>
포화 이진트리는 모든 노드가 꽉 차있는 상태의 이진트리이다.<br>
노드의 개수는 2^높이-1로 계산된다.<br>
2.완전이진트리<br>
아까 이진트리란?에서 부여한 번호 순서대로(위에서 아래로, 왼쪽부터 오른쪽으로 붙인다.) 노드가 배치된다.<br>
노드가 일부 비어있어도 되지만, 번호 순서대로  왼쪽부터 오른쪽으로 채워져 있어야 한다.<br>
3.편향이진트리<br>
편향이진트리는 모든 노드가 왼쪽이나 오른쪽으로 연결된 트리다.<br>

이진트리 구조<br>
트리는 왼쪽자식과 오른쪽 자식으로 구성된다.<br>
그러므로 오른쪽과 왼쪽 링크가 있는 이중연결리스트 구조로 만들 수 있다.<br>

5.이동한 오른쪽 서브 트리(루트의 왼쪽 자식의 오른쪽 자식)의 데이터를 먼저 처리하고, 왼쪽 서브트리를 처리한다. 만약 없다면 오른쪽 서브트리를 처리한다. 만약 그것도 없다면 오른쪽 서브트리(루트의 왼쪽 자식의 오른쪽 자식)는 처리가 완료되었다.<br>
6.현재노드(루트의 왼쪽 자식의 오른쪽 자식)는 처리가 완료되었으니  윗 노드(루트의 왼쪽 자식)로 올라간다. 루트의 왼쪽 자식도 처리되었으니 루트로 올라간다음 오른쪽 서브트리로(루트의 오른쪽 자식)으로 이동한다.<br>
7.이동한 오른쪽 서브트리(루트의 오른쪽 자식)의 데이터를 먼저 처리하고 왼쪽 서브트리(루트의 오른쪽 자식의 왼쪽 자식)로 이동한다.<br>
8.이동한 서브트리(루트의 오른쪽 자식의 왼쪽자식)의 데이터를먼저 처리하고 다시 왼쪽서브트리(루트의 오른쪽 자식의<br> 왼쪽자식의 왼쪽자식)를 처리한다. 만약 없다면 오른쪽 서브트리(루트의 오른쪽 자식의 오른쪽 자식)를 처리한다. 그것도 <br>없다면 루트의 오른쪽 자식의 왼쪽자식은 처리가 완료되었다. 그리고 모든 노드 순회가 완료되었다.<br>

이 순서를 보면 현재 데이터(루트)->왼쪽서브트리->오른쪽 서브트리 순서로 처리된 것을 알 수 있다.<br>

**이진탐색트리 규칙**<br>
1. 왼쪽 서브 트리는 루트노드보다 모두 작은 값을 가진다.<br>
2. 오른쪽 서브트리는 루트 노드보다 모두 큰 값을가진다.<br>
3. 각 서브 트리도 1,2의 특징을 가진다.<br>
4. 모든 노드 값은 중복되지 않는다. 즉, 중복된 값은 이진 탐색트리에 저장할 수없다.<br>

## 원형큐

**1.원형큐의 개념**<br>
원형큐는 큐의 처음과 끝이 연결된 구조이다.<br>
순차 큐처럼 배열로 구현하되, 큐의 끝에 다다르면 다시 처음으로 이어지도록처리하면 된다.<br>
앞이 빈 순차큐 10만개를 옮기려면 앞의 칸에서부터 99999번 칸까지 한칸씩 옮겨야 한다. 이렇게되면 오버헤드가 발생한다.<br>
오버헤드:특정 작업을 처리하기 위해 직접적으로 필요한 핵심 연산 외에, 시스템 관리나 데이터 구조 유지 등을 위해<br>부수적으로 소모되는 시간이나 메모리를 말한다.<br>
반면 원형큐는  앞이 비어도 rear를 처음으로 이동시킨 후 그 자리에 데이터를 입력하면 끝난다.훤씬 효율적이다.<br>

rear+1과 front가 같은 경우에 원형큐가 꽉 찬 것으로 처리된다. <br>

## 순차 큐
---
큐는 FIFO(First In First Out)구조이다.<br>
큐는 처음 들어간 데이터가 처음 나온다.<br>
큐에 데이터를 넣는 과정을 enQueue(인큐)라고하고, 큐에 데이터를 추출하는 과정을 deQueue(데큐)라고 한다.<br>
큐에는 front(머리)와 rear(꼬리)가 있다.<br>
큐에 데이터를 삽입할때는 꼬리 다음 위치에 삽입한다.<br>
큐에 데이터를 추출할때는 머리 위치가 추출된다.<br>
교재에서 큐는 오른쪽이 입구, 왼쪽이 출구이다.<br>

아무런 데이터가 없을때는 front와 rear가 모두 -1이다<br>
### 데이터 삽입 enQueue<br>
데이터를 큐에 추가(enQueue)하면 rear가 오른쪽으로 한칸 이동한다.<br>
 +(+:"추가로" 라는 뜻)기존에 아무런 데이터가 없을때는 rear가 -1이므로, 0이된다<br>
 +front는 여전히 -1이다.<br>

출구는 하나 뿐이므로 오른쪽에서 들어온 데이터가 왼쪽으로 나갈 수밖에 없다.<br>
